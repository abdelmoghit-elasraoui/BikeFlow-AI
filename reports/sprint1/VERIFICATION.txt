BIKEFLOW AI - SPRINT 1 COMMANDS
Repo: https://github.com/abdelmoghit-elasraoui/BikeFlow-AI
MAC = run on the Mac, inside the repo folder
VPS = run on the Windows VPS (or prefix with: ssh bikeflow "...")


SETUP AND TESTS

[MAC] Install dependencies
uv sync --locked --extra dev

[MAC] Check Python version
uv run python --version

[MAC] Run all tests
uv run pytest -q

[MAC] Lint
uv run ruff check src tests

[MAC] Check formatting
uv run ruff format --check src tests


DATA

[MAC] List downloaded trip archives
ls -lh data/raw/trips/

[MAC] Show targets manifest (checksums, row counts)
cat data/processed/session2/manifest.json

[MAC] Count Parquet target rows
uv run python -c "import pyarrow.parquet as pq; [print(n, sum(pq.read_metadata(f.path).num_rows for f in pq.ParquetDataset('data/processed/session2/'+n).fragments), 'rows') for n in ('targets_30min','targets_60min')]"

[MAC] Show baseline v0 scores
cat data/processed/session2/baseline_v0.json


MODEL

[MAC] Retrain the four models
uv run bikeflow train --version v1

[MAC] List model artifacts
ls -lh data/models/v1/

[MAC] Show model vs baseline table
uv run python -c "import json; m=json.load(open('data/models/v1/metrics.json')); [print(h, f, 'model', round(r['model_mae'],3), '| baseline', round(r['baseline_mae'],3), '|', str(round(r['improvement_pct'],1))+'%') for h,hv in m['horizons'].items() for f,r in hv['flows'].items()]"

[MAC] Show committed sprint report
cat reports/sprint1/REPORT.md


VPS COLLECTION

[VPS] Check collector task state
schtasks /query /tn BikeFlowCollector /fo LIST | findstr Status

[VPS] Show collection coverage
cd /d C:\BikeFlow && .venv\Scripts\bikeflow.exe --data-dir C:\BikeFlow\data coverage

[VPS] Tail the live collector log
powershell -Command "Get-Content C:\BikeFlow\data\collect.log -Tail 3"

[VPS] Count raw snapshots
powershell -Command "(Get-ChildItem C:\BikeFlow\data\raw\gbfs -Recurse -Filter *.json.gz | Measure-Object).Count"

[VPS] Show raw snapshot disk usage
powershell -Command "'{0:N1} GB' -f ((Get-ChildItem C:\BikeFlow\data\raw\gbfs -Recurse -Filter *.json.gz | Measure-Object Length -Sum).Sum/1GB)"


API

[MAC] Open the SSH tunnel to the VPS API
ssh -f -N -L 8000:127.0.0.1:8000 bikeflow

[MAC] Check the tunnel is listening
lsof -nP -iTCP:8000 -sTCP:LISTEN

[MAC] Health check
curl -s localhost:8000/health | python3 -m json.tool

[MAC] Snapshot freshness
curl -s localhost:8000/freshness | python3 -m json.tool

[MAC] List eligible stations
curl -s "localhost:8000/stations?eligible_only=true" | python3 -c "import json,sys; d=json.load(sys.stdin); print('count', d['count'], 'snapshot', d['snapshot']['poll_id'])"

[MAC] Forecast one station, 30 minutes
curl -s "localhost:8000/forecasts/1869743938848725856?horizon=30" | python3 -m json.tool

[MAC] Forecast one station, 60 minutes
curl -s "localhost:8000/forecasts/1869743938848725856?horizon=60" | python3 -m json.tool

[MAC] Ranked rebalancing queue
curl -s "localhost:8000/queue?horizon=30&limit=5" | python3 -c "import json,sys; q=json.load(sys.stdin); [print(r['station_id'][:12], r['recommendation'], round(r['warning_score'],2), 'bikes', r['current_bikes'], 'docks', r['current_docks']) for r in q['queue']]"

[MAC] Show persisted predictions
curl -s "localhost:8000/predictions?limit=3" | python3 -m json.tool

[MAC] List API paths
curl -s localhost:8000/openapi.json | python3 -c "import json,sys; print(', '.join(sorted(json.load(sys.stdin)['paths'])))"

[MAC] Open interactive API docs
open http://localhost:8000/docs

[VPS] Check API task state
schtasks /query /tn BikeFlowAPI /fo LIST | findstr Status


SECURITY

[MAC] Confirm no secrets or data are tracked by Git
git ls-files | grep -E "\.env$|\.sqlite$|data/|\.venv" || echo "clean"
